About Nepal Real Estate

A machine-learning powered platform designed to help users understand property prices and make more informed real-estate decisions in Nepal.

The Problem

Property prices can vary significantly depending on location, area, road access, property characteristics, and other factors. Buyers may struggle to determine whether a property's asking price is reasonable, while sellers may have difficulty estimating an appropriate price.

This project uses historical property data and machine learning to provide a data-driven price estimate and identify listings that may be worth further investigation.

What This Platform Does

🤖

Price Prediction

Estimates the expected property price using a trained Random Forest regression model.

📊

Market Comparison

Compares the listed property price with the model's estimated price.

💡

Potential Opportunities

Highlights properties where the listed price is lower than the model estimate.

Machine Learning Approach

The system uses supervised machine learning for property price regression. Several property characteristics are used as input features, including location, area, bedrooms, bathrooms, floors, parking, road width, property age, facing, road type, and amenities.

Random Forest was selected as the model used by the application after comparing regression models during the project analysis.
